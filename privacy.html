Hjem privacy policy

Hjem is a private tool used by one household. Only the family's own Google account is connected to it.

What Hjem accesses

  • Google Calendar: reads upcoming events and creates or updates events that a family member has confirmed.
  • Gmail: sends notices to the family's own email addresses when the chat is unavailable. Hjem does not read email.

How data is handled

  • Data is used only to run Hjem for the household. It is never sold, shared with third parties or used for advertising.
  • A short-lived copy of calendar events is kept in a private database so the daily overview works when Google is unreachable.
  • Hjem's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
